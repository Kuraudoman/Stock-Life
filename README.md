# Stock-Life

2D 二次元风格的轻量 PC 股市模拟游戏（工作名）。玩家在赫尔墨斯帝国首都奥鲁姆，扮演背负 50,000 金币债务的见习交易员希雅，靠读新闻、交朋友、低买高卖成为“帝国股神”。

完整设计见 [docs/GDD.md](docs/GDD.md)。

## 运行

1. 安装 **Godot 4.7.2**（标准版，非 .NET 版）。项目使用 GL Compatibility 渲染器。
2. 用 Godot 打开 `project.godot`，按 F5 运行。

### 怎么玩

- 每天开盘前先读晨报。「要闻」已经反映在开盘价里；「市场」栏的风声才是前兆——真正的消息 1–5 个交易日后出现，但不会说是哪天。传闻真假参半。
- 右下角「开盘」开始一天；空格键暂停 / 继续，「快进到收盘」直接跳到 15:00。盘中出快讯会自动暂停。
- 点左上角的主角立绘请她预测走势。她的准确度取决于状态标签和脸色：平静健康时最靠谱，狂热、恐慌、生病时会离谱甚至说反，界面不显示准确率。每天最多 3 次，每次消耗体力。
- 收盘后进入城市地图。工作日有 2 个行动点，周六、周日各有 4 个。早点休息、和诺艾尔复盘、去学院进修，或者回家睡觉。什么都不做直接睡觉，和早点休息一样。累了行动点变少，发烧就只能休息。
- 顶栏「还款」把现金还给黑鸦商会，还清 50,000 即通关。期限是 4 月 30 日收盘。名声、住所和进修写在顶栏「名声」的提示里，调查度这版不会涨。

颜色约定：**红涨绿跌**。

### 平衡

`simulate.gd` 用 6 种机器人各跑第一章（只用玩家看得到的信息），期限收盘时的清算价值 ≥ 50,000 算赢。400 局（种子 1–400）的结果：

| 策略 | 胜率 | 清算价值中位数 | P90 | 说明 |
|---|---|---|---|---|
| 持有不动 | 9.0% | 1.12 倍 | 1.24 倍 | 开局等权买入 5 支股票。晚上不进城，和 v0.2.0 相同 |
| 随机买卖 | 0.0% | 0.94 倍 | 1.07 倍 | 手续费和滑点吃掉一切 |
| 只听预测 | 21.2% | 1.07 倍 | 1.32 倍 | 每天问 3 次“今天收盘前”，买她说涨的；晚上体力够就去学院进修再休息一次。说中约 68%（v0.2.0 不进修时约 60%、胜率 10.5%） |
| 反着听预测 | 0.0% | 0.75 倍 | 0.93 倍 | 不看状态一律反着听，晚上不进修 |
| 读报 | 76.8% | 1.39 倍 | 1.70 倍 | 看到带方向的前兆就买，消息出来后第二天卖，盘中快讯追利好、躲利空 |
| 读报 + 预测 | 76.2% | 1.37 倍 | 1.64 倍 | 买之前问一次，她说跌就放弃。晚上仍早点休息：学费和少睡会把刚好还清的局拖下去 |

会读报的玩家大多还能赢，只持有、乱买、只听预测（即便把进修练满）基本赢不了。只听预测从 10.5% 升到 21.2%，中位数仍只有 1.07 倍，到不了还债需要的 1.25 倍。读报和读报+预测与 v0.2.0 的 76.8% / 76.3% 一样，差在抽样噪声里。

GDD 初稿的起始现金是 10,000（要翻 5 倍）。模拟显示连“读报”机器人的中位数都只有 1.4 倍左右，5 倍在 22 个交易日里几乎不可能，所以起始现金暂定 **40,000**（债务仍是 50,000，需要赚 25%）。数值在 `data/chapter1.json` 和 `data/evening.json`，试玩后再调。

## 界面素材

界面贴图来自 Kenney 的 [UI Pack - Pixel Adventure](https://kenney.nl/assets/ui-pack-pixel-adventure)（CC0，许可见 `assets/ui/kenney/License.txt`），只用 Large tiles / Thin outline，按 1:1 像素显示（项目已设为最近邻采样）。按钮各状态、买入红 / 卖出绿、输入框是对原图做调色板替换生成的。

素材包放在项目旁边的 `UI Pack/kenney_ui-pack-pixel-adventure`，改了配色或换了图块后重新生成：

```bash
godot --headless --path . --script res://tools/build_ui_assets.gd -- --pack "../UI Pack/kenney_ui-pack-pixel-adventure"
```

代码里用到的颜色集中在 `scripts/ui/ui_style.gd`。主题里的变体：`FeaturePanel`（带金属包角的重点面板）、`RibbonLabel` / `RibbonTitle`（红色缎带标题）、`BuyButton` / `SellButton`、`StockRow`。

## 存档

| 运行方式 | saves 文件夹位置 |
|---|---|
| 在 Godot 编辑器中运行 | 项目根目录下的 `saves/` |
| 导出的游戏（Windows / Linux） | 可执行文件所在目录下的 `saves/` |
| macOS 导出版，或游戏目录不可写 | 用户数据目录 `user://saves`（标题界面会显示实际路径） |

- 文件名 `<存档名>.stocklife.json`；顶栏「存档」写入 `slot1`，每天收盘自动写入 `autosave`（第一章失败那天除外）。晚间结束、进入下一个交易日之前会再存一次，周末在城里做的事不会丢。
- 把存档文件复制到另一台电脑的 saves 文件夹即可继续游戏。
- 存档里保存了随机数状态和事件日程，读档后的行情、新闻与不中断时完全一致。
- 存档版本 3（M2 晚间）。版本 2 会补上「当晚还没开始」以及阁楼 / 步行 / 平民服；版本 1 先升到 2（补事件日程、跳过开场），再升到 3。主角的新字段由 `Life.normalize` 补齐。

## 导出 Windows 版本

1. 编辑器菜单「编辑器 → 管理导出模板」，下载 4.7.2 的导出模板。
2. 「项目 → 导出」，选择已配置好的 **Windows Desktop** 预设，导出到 `build/Stock-Life.exe`（单个 exe，已内嵌 pck）。
3. 发布压缩包时附带一个空的 `saves` 文件夹。

## 给后续 M2 留的接口

晚间行动已经接上。下面这些还是空的，数据在 `data/evening.json`，结算在 `Evening.resolve_hook()`：

- `rumor`：拜访米娅（`hook_rumor_mia`）、酒馆听传闻（`hook_rumor_tavern`）。现在只加一点好感或听一段闲话。
- `investigate`：魔导工坊、龙运码头。现在只记 `hook_investigate_<公司>` 和 1 点名声。
- `insider`：向渡鸦夫人买内幕。按钮锁着，数据里写了以后要加的调查度，这版不加。
- `rival`：贵族沙龙。进得去也只是听到维多利亚的名字，`hook_rival_victoria` 加一，没有大单。
- `invite`：宅邸以上才能请客，按钮仍锁着。
- `GameState.choose_evening("rest" / "review")` 还在，给测试和「跳过城区」的脚本用。玩家界面走 `open_evening` / `perform_evening_action` / `finish_evening`。
- `Market.set_phase("dawn" | "boom" | "mania" | "crash")`：经济阶段。第二章起在 `data/chapterN.json` 里指定。
- `player.heat` 已在存档和顶栏里，还没有上升和赛琳的剧情。
