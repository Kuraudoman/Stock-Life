# 立绘文件

每个角色一个目录：`assets/portraits/<角色 id>/`。希雅是 `heroine`。没有图的角色仍用代码画的占位半身像。

只有一套图，透明背景的 PNG，文件名就是表情名，不带描边变体：

`<表情>.png`

没有这张表情时，先试 `smile.png`，再试 `normal.png`。还是没有，才用代码画的占位。

## 希雅

尺寸 **1088×1440**。人物都顶到画面上沿，代码按槽的高度等比缩放、水平居中。槽比图窄时只裁左右，不裁头顶，也不变形。

- `smile.png` — 平静
- `grin.png` — 乐观
- `frown.png` — 悲观
- `coin.png` — 狂热
- `panic.png` — 恐慌
- `sleepy.png` — 疲劳
- `cold.png` — 感冒
- `dizzy.png` — 发烧
- `hospital.png` — 住院
- `cry.png` — 对话里的哭（失败）
- `ecstatic.png` — 结局里的高兴

发带上沿和 smile 比过：悲观因为头顶的雨云低了 124 像素，疲劳低了 25 像素。这两张在绘制时往上让（`portrait_painter.gd` 的 `TOP_PAD`），文件本身不改。其余表情和 smile 相差不到 10 像素，不再移动。

身体状态优先于情绪：住院、发烧、感冒、疲劳各用自己的整张图，健康时才按平静 / 乐观 / 悲观 / 狂热 / 恐慌换。

导入时生成 mipmap，绘制时用线性过滤。不是像素素材。
